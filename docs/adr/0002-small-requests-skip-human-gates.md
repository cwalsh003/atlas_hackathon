# Small requests skip the human plan and merge gates

This repository's Atlas policy requires a human to approve the plan, move work to in-progress, and merge the PR. For implement-lane requests that triage sizes `small` (one region, no new data fields, no new dependency) the agent implements, opens the PR, merges it, and labels the request shipped with no human click. We accepted this because the change is behind a per-request flag (see ADR 0001), so a bad merge is invisible until a viewer turns it on and can be dropped in consolidation, and because a live demo needs a small change to land in minutes. Large requests and the consolidation PR keep every human gate. The policy edit lives in `docs/agents/issue-tracker.md` as a team edit, not in the generated Atlas sections.
